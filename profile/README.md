# Project Overview

Corsair iCUE is device management and customization software for compatible Corsair gaming peripherals, PC components, cooling hardware, and RGB lighting devices.

It provides a centralized interface for configuring lighting, performance profiles, macros, fan curves, cooling settings, sensors, and supported Corsair hardware.

---

- Corsair device management
- RGB lighting control
- Custom lighting effects
- Device synchronization
- Mouse DPI configuration
- Keyboard assignments
- Macro creation
- Gaming profiles
- Fan speed control
- Custom fan curves
- Cooling configuration
- Temperature monitoring
- Hardware sensor monitoring
- Performance profiles
- Audio device settings
- Device firmware management

Available functionality depends on connected hardware, firmware, iCUE version, and system configuration.

# Troubleshooting

If a device is not detected, check USB or wireless connectivity, restart iCUE, and verify that the hardware is supported.

For RGB or cooling problems, review device configuration, active profiles, firmware, controller connections, and sensor assignments.

Avoid aggressive fan or pump configurations without considering hardware temperature requirements.
